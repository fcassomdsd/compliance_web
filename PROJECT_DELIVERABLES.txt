================================================================================
                             DATA MODELS SUPPORTED
================================================================================

PROTOCOL QUESTION ENTITY:
  - id: Unique identifier
  - activo: Boolean flag for active questions
  - code: Human-readable code
  - normativas: Associated regulations
  - references: References to documentation
  - topic: Link to Question Topic entity
  - sequence: Ordering number
  - verification: Compliance verification guidelines
  - texto: Question text
  - specialty: Associated specialty

INSPECTION QUESTION ENTITY:
  - id: Unique identifier
  - code: Question code
  - inspectedSpecialty: Link to inspected specialty
  - protocolQuestion: Link to protocol question

QUESTION TOPIC ENTITY:
  - id: Topic identifier
  - name: Topic display name

INSPECTED SPECIALTY ENTITY:
  - id: Unique identifier
  - specialtyName: Display name
  - specialtyId: Link to specialty
  - inspectedServiceId: Link to service

================================================================================
                            HOW TO USE (QUICK START)
================================================================================

1. Navigate to "Inspection Checklist" in the app
2. Select a specialty from the dropdown
3. Review available questions (grouped by topic)
4. Select desired questions using:
   - Individual checkboxes
   - Per-topic "Select All/Clear All" buttons
   - Global "Select All/Clear All" buttons
5. Click "Save Checklist"
6. Success message will appear

For detailed instructions, see CHECKLIST_QUICK_START.md
